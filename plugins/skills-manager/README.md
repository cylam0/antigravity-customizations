# Antigravity Skills Manager

A native UI extension plugin for Google Antigravity to toggle skills on/off (suppressing slash `/` commands) and view/edit `SKILL.md` files.

## Installation

Clone this repository directly into your Antigravity global plugins directory:

### Windows (PowerShell)
```powershell
git clone <your-repo-url> "$env:USERPROFILE\.gemini\config\plugins\skills-manager"
```

### macOS / Linux
```bash
git clone <your-repo-url> ~/.gemini/config/plugins/skills-manager
```

## How to Enable

1. Open Antigravity.
2. Go to **Customizations** in the left sidebar > **Installed** tab.
3. Find **skills-manager** and toggle it **Enabled**.
4. In any conversation, open the **⋮** (three-dot) menu in the top right > **Extensions** > **Skills Manager**.
